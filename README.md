# aiyaohua · 爱要画

中文艺术与视觉灵感首页，纯 HTML/CSS/JavaScript，无需构建或依赖。

## 页面内容
- 响应式首页和移动端导航
- 原创 SVG 风格示意画廊、分类筛选、详情弹窗
- 浏览器本地提示词组合与复制（不调用 AI，不生成图片）
- SEO 标题、描述、canonical、Open Graph、WebSite 结构化数据和 sitemap

## 发布到 GitHub Pages
1. 打开仓库 Settings → Pages。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **main**，Folder 选择 **/(root)**，点击 Save。
4. 发布完成后访问 https://zhaoyao75.github.io/aiyaohua/ 。

如 Settings → Pages 已选择其他部署来源，请保持或按上述方式切换。

## Google 收录
在 Search Console 中添加网址前缀 https://zhaoyao75.github.io/aiyaohua/ ，按指引验证所有权，再提交 https://zhaoyao75.github.io/aiyaohua/sitemap.xml 。HTML 验证文件应上传到仓库根目录；也可以将官方提供的验证 meta 标签加入 index.html 的 head。不要自行编造验证码。网站上线不代表已被 Google 收录。

## 编辑
直接修改 index.html。插画为内嵌 SVG，不依赖外部图片或字体。更换域名时，同步更新 canonical、Open Graph URL、结构化数据及 sitemap。
